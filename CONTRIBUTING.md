# Contributing

The project is currently local and unpublished. Contributors should keep changes in small modules, use typed Python interfaces, preserve Uzbek/English/Russian parity, and add meaningful tests for parsers, security boundaries and data accuracy. Run `.venv/bin/python -m pytest -q`, `node --check frontend/js/app.js`, and the local real/demo smoke tests before proposing a completed milestone. Do not include personal telemetry, secrets, SQLite databases, or hardware identifiers in commits or screenshots.
