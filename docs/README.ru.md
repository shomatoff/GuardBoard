# GuardBoard — руководство на русском

[English](../README.md) · [O‘zbekcha](README.uz.md) · **Русский**

GuardBoard — приложение с открытым исходным кодом для локального просмотра состояния Linux, сети и отдельных защитных проверок. Версия `v0.1.0-dev.1` является предварительной: работают десять разделов, реальные показания доступных датчиков, наблюдение за сетью и Wi-Fi, ограниченная проверка целостности выбранного проекта, управление сканированием ClamAV и справка на трёх языках. Не все запланированные функции безопасности реализованы.

## Загрузка и запуск

Скачайте `GuardBoard-Linux-x64.tar.gz` и `SHA256SUMS` с одной страницы [GitHub Releases](https://github.com/shomatoff/GuardBoard/releases). В каталоге загрузки выполните:

```bash
sha256sum -c SHA256SUMS
tar -xzf GuardBoard-Linux-x64.tar.gz
./GuardBoard/GuardBoard
```

Откройте в браузере адрес `http://127.0.0.1:.../?key=...`, напечатанный в терминале. Оставьте терминал открытым; `Ctrl+C` остановит приложение. Демо запускается командой `./GuardBoard/GuardBoard --demo`. Архив не подписан и первоначально проверен на Ubuntu 24.04 x64. Реальный режим хранит локальные данные в `~/.local/share/guardboard`.

Запуск из исходников: `python3 -m venv .venv`, `.venv/bin/pip install -r requirements.txt`, затем `./run.sh`.

## Безопасность и ограничения

Сервер слушает только `127.0.0.1`, вход защищён ключом сеанса, настройки системы автоматически не меняются. Внешние запросы и сканирование проектов требуют действия пользователя. Изменение правил межсетевого экрана, управление VPN, резервное копирование и восстановление, применение профилей оптимизации и откат пока отсутствуют. При недостатке доказательств оценка безопасности остаётся неизвестной. Чистый результат антивируса не гарантирует полной защиты.
